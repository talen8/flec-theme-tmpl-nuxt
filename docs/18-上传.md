# 上传

文件上传相关的函数。

## useUpload

文件上传。

```ts
const { upload, uploading, progress } = useUpload()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `upload` | `(file: File, type?: UploadType) => Promise<UploadResponse>` | 上传文件 |
| `uploading` | `Ref<boolean>` | 上传中状态 |
| `progress` | `Ref<number>` | 上传进度 (0-100) |

**UploadResponse 结构：**

```ts
interface UploadResponse {
  url: string      // 文件访问地址
  name: string     // 文件名
  size: number     // 文件大小
}
```

**UploadType 类型：**

```ts
type UploadType = 'image' | 'file'
```

**示例：**

```vue
<script setup>
const { upload, uploading, progress } = useUpload()

const handleFileChange = async (event) => {
  const file = event.target.files[0]
  if (file) {
    const result = await upload(file, 'image')
    console.log('上传成功:', result.url)
  }
}
</script>

<template>
  <input type="file" @change="handleFileChange" :disabled="uploading" />
  <div v-if="uploading">上传中... {{ progress }}%</div>
</template>
```

## API 函数

### uploadFile

上传单文件。

```ts
const result = await uploadFile(file, type)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `file` | `File` | 文件对象 |
| `type` | `UploadType` | 上传类型（'image' 或 'file'） |

**返回值：** `UploadResponse`

**示例：**

```ts
const result = await uploadFile(myFile, 'image')
console.log(result.url) // 文件访问地址
```

**使用场景：**
- 头像上传
- 图片上传
- 文件附件
