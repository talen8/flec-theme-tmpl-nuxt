# 动态

动态列表、音乐播放器相关的函数。

## useMomentList

获取动态列表（支持 SSR）。

```ts
const { data, page, totalPages, loading } = useMomentList(pageSize?)
```

**参数：**

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `pageSize` | `MaybeRefOrGetter<number>` | `30` | 每页数量 |

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `data` | `Ref<Moment[]>` | 动态数组 |
| `refresh` | `() => Promise<void>` | 刷新方法 |

**Moment 结构：**

```ts
interface Moment {
  id: number
  content: string
  images: string[]
  music?: MomentMusic
  likes: number
  comments: number
  is_liked: boolean
  created_at: string
  user: {
    id: number
    nickname: string
    avatar: string
  }
}
```

**示例：**

```vue
<script setup>
const { data: moments } = useMomentList(20)
</script>

<template>
  <div v-for="moment in moments" :key="moment.id">
    <p>{{ moment.content }}</p>
    <div v-if="moment.images?.length" class="images">
      <img v-for="img in moment.images" :key="img" :src="img" />
    </div>
    <span>{{ formatMomentTime(moment.created_at) }}</span>
  </div>
</template>
```

## useMusic

音乐播放器状态管理（通过 Meting API 加载音频信息）。

```ts
const { tracks, loading, error, load, fetchLyrics } = useMusic(music)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `music` | `MaybeRefOrGetter<MomentMusic>` | 音乐数据，支持 ref / computed / getter |

**MomentMusic 结构：**

```ts
interface MomentMusic {
  server: string  // 音乐平台（netease、tencent、kugou 等）
  type: string    // 类型（song、playlist、album 等）
  id: string      // 音乐 ID
}
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `tracks` | `Ref<AudioTrack[]>` | 音轨列表 |
| `loading` | `Ref<boolean>` | 加载状态 |
| `error` | `Ref<boolean>` | 错误状态 |
| `load` | `() => Promise<void>` | 加载音乐 |
| `fetchLyrics` | `(lrc: string) => Promise<LyricLine[]>` | 解析歌词 |

**AudioTrack 结构：**

```ts
interface AudioTrack {
  name: string    // 歌曲名
  artist: string  // 艺术家
  url: string     // 音频 URL
  cover: string   // 封面 URL
  lrc: string     // 歌词 URL 或文本
}
```

**LyricLine 结构：**

```ts
interface LyricLine {
  time: number  // 时间点（秒）
  text: string  // 歌词文本
}
```

**示例：**

```vue
<script setup>
const musicData = {
  server: 'netease',
  type: 'song',
  id: '123456'
}

const { tracks, loading, load, fetchLyrics } = useMusic(musicData)

onMounted(() => load())
</script>

<template>
  <div v-if="loading">加载中...</div>
  <div v-else>
    <div v-for="track in tracks" :key="track.url">
      <img :src="track.cover" :alt="track.name" />
      <span>{{ track.name }} - {{ track.artist }}</span>
      <audio :src="track.url" controls />
    </div>
  </div>
</template>
```

## API 函数

### getMoments

获取动态列表。

```ts
const data = await getMoments({ page: 1, page_size: 20 })
// 返回: { list: Moment[], total, page, page_size }
```
