# 通知

通知列表、已读相关的函数。

## useNotifications

获取通知列表和未读数。

```ts
const { notifications, unreadCount, loading, fetchNotifications } = useNotifications()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `notifications` | `Ref<Notification[]>` | 通知列表 |
| `unreadCount` | `Ref<number>` | 未读数量 |
| `loading` | `Ref<boolean>` | 加载状态 |
| `fetchNotifications` | `() => Promise<void>` | 获取通知 |

**Notification 结构：**

```ts
interface Notification {
  id: number
  type: NotificationType
  title: string
  content: string
  is_read: boolean
  created_at: string
  data?: Record<string, any>
}
```

**NotificationType 类型：**

```ts
type NotificationType = 
  | 'comment'      // 评论通知
  | 'reply'        // 回复通知
  | 'system'       // 系统通知
  | 'subscribe'    // 订阅通知
```

**示例：**

```vue
<script setup>
const { notifications, unreadCount } = useNotifications()
</script>

<template>
  <div>
    <span v-if="unreadCount > 0">{{ unreadCount }} 条未读</span>
    <div v-for="notif in notifications" :key="notif.id">
      <h4>{{ notif.title }}</h4>
      <p>{{ notif.content }}</p>
      <span>{{ formatRelativeTime(notif.created_at) }}</span>
    </div>
  </div>
</template>
```

## API 函数

### getNotifications

获取通知列表。

```ts
const data = await getNotifications()
// 返回: { list: Notification[], total, unread_count }
```

### markAsRead

标记单条通知为已读。

```ts
await markAsRead(123)
```

### markAllAsRead

标记所有通知为已读。

```ts
await markAllAsRead()
```
