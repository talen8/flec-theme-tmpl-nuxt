# 滚动

滚动控制相关的函数。

## scrollToTop

平滑回到顶部。

```ts
scrollToTop()
```

**示例：**

```vue
<template>
  <button @click="scrollToTop">回到顶部</button>
</template>
```

## scrollToElement

滚动到指定元素。

```ts
scrollToElement(selector)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `selector` | `string` | CSS 选择器 |

**示例：**

```vue
<template>
  <button @click="scrollToElement('#comments')">跳转到评论</button>
  
  <div id="comments">
    <!-- 评论区 -->
  </div>
</template>
```

**使用场景：**
- 目录导航点击后滚动到对应标题
- 评论区跳转
- 锚点链接

**示例 - 目录导航：**

```vue
<script setup>
const toc = [
  { id: 'section-1', text: '第一章' },
  { id: 'section-2', text: '第二章' },
]

const handleClick = (id) => {
  scrollToElement(`#${id}`)
}
</script>

<template>
  <nav>
    <a v-for="item in toc" :key="item.id" @click.prevent="handleClick(item.id)">
      {{ item.text }}
    </a>
  </nav>
</template>
```
