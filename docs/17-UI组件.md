# UI

Toast 消息、展开收起相关的函数。

## useToast

Toast 消息提示。

```ts
const { success, error, warning, info } = useToast()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `success` | `(message: string, duration?: number) => void` | 成功提示 |
| `error` | `(message: string, duration?: number) => void` | 错误提示 |
| `warning` | `(message: string, duration?: number) => void` | 警告提示 |
| `info` | `(message: string, duration?: number) => void` | 信息提示 |

**参数：**

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `message` | `string` | - | 提示消息 |
| `duration` | `number` | 3000 | 显示时长（毫秒） |

**示例：**

```vue
<script setup>
const { success, error } = useToast()

const handleSave = async () => {
  try {
    await saveData()
    success('保存成功')
  } catch (e) {
    error('保存失败')
  }
}
</script>

<template>
  <button @click="handleSave">保存</button>
</template>
```

## useExpandable

内容展开/收起。

```ts
const { isExpanded, toggle, expand, collapse } = useExpandable(initialState?)
```

**参数：**

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `initialState` | `boolean` | `false` | 初始状态 |

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `isExpanded` | `Ref<boolean>` | 是否展开 |
| `toggle` | `() => void` | 切换展开/收起 |
| `expand` | `() => void` | 展开 |
| `collapse` | `() => void` | 收起 |

**示例：**

```vue
<script setup>
const { isExpanded, toggle } = useExpandable()
</script>

<template>
  <div>
    <button @click="toggle">
      {{ isExpanded ? '收起' : '展开' }}
    </button>
    <div v-show="isExpanded">
      <p>这里是展开的内容...</p>
    </div>
  </div>
</template>
```

**使用场景：**
- 文章摘要展开
- 评论折叠
- 长文本截断
- 侧边栏折叠
