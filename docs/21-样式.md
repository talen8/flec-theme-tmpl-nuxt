# 样式

包提供 `base.css` 和 `prose.css`，会在 `extends` 时自动加载。

## base.css

CSS 重置和基础样式。

**包含内容：**
- CSS Reset（清除浏览器默认样式）
- RemixIcon 字体图标
- 基础排版

**覆盖方式：**

在主题中创建同名选择器即可覆盖：

```css
/* app/assets/css/base.css */
:root {
  --primary: #1a73e8;
  --text: #333;
}
```

## prose.css

文章内容完整排版样式（亮/暗双主题）。

**包含内容：**

- 标题（h1-h6）
- 段落
- 代码块（行内代码、多行代码块）
- 表格
- 引用块
- 列表（有序、无序）
- 链接
- 图片
- 自定义卡片（提示框、警告框等）
- 数学公式（KaTeX）
- 任务列表
- 脚注

**覆盖方式：**

```css
/* app/assets/css/prose.css */
.prose h1 {
  font-size: 2rem;
  margin-bottom: 1.5rem;
}

.prose code {
  background: #f5f5f5;
  padding: 2px 6px;
  border-radius: 4px;
}

.prose blockquote {
  border-left: 4px solid #1a73e8;
  padding-left: 1rem;
  color: #666;
}
```

## 自定义主题样式

在 `nuxt.config.ts` 中添加自定义样式：

```ts
export default defineNuxtConfig({
  extends: ['@flecblog/core-nuxt'],
  css: [
    '@/assets/css/custom.css',
    '@/assets/css/theme.scss',
  ],
})
```

## CSS 变量

建议使用 CSS 变量来实现主题定制：

```css
:root {
  --primary: #1a73e8;
  --primary-light: #4285f4;
  --primary-dark: #1557b0;
  
  --text: #333;
  --text-secondary: #666;
  --text-tertiary: #999;
  
  --bg: #f5f5f5;
  --bg-card: #fff;
  --bg-hover: #f0f0f0;
  
  --border: #eee;
  --shadow: 0 2px 8px rgba(0, 0, 0, 0.06);
}

[data-theme="dark"] {
  --primary: #4285f4;
  --text: #e0e0e0;
  --text-secondary: #aaa;
  --bg: #1a1a1a;
  --bg-card: #2a2a2a;
  --border: #333;
  --shadow: 0 2px 8px rgba(0, 0, 0, 0.2);
}
```

然后在组件中使用：

```vue
<style scoped>
.card {
  background: var(--bg-card);
  color: var(--text);
  border: 1px solid var(--border);
  box-shadow: var(--shadow);
}
</style>
```
