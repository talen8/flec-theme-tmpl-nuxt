# 工具

JSON 解析、API 工厂等工具函数。

## parseJSON

安全解析 JSON（不会抛出异常）。

```ts
const result = parseJSON(jsonStr, fallback)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `jsonStr` | `string \| undefined \| object \| null` | JSON 字符串或对象 |
| `fallback` | `any` | 解析失败时的默认值 |

**返回值：** 解析结果或默认值

**示例：**

```ts
const data = parseJSON('{"name": "test"}', {})
// 返回: { name: "test" }

const fallback = parseJSON('invalid json', {})
// 返回: {}

const obj = parseJSON({ name: 'test' }, {})
// 返回: { name: "test" } (已是对象，直接返回)

const nullResult = parseJSON(null, [])
// 返回: [] (null 返回默认值)
```

## createApi

创建 API 工厂实例。

```ts
const api = createApi<T>(endpoint, options?)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `endpoint` | `string` | API 端点路径，如 `/articles` |
| `options` | `ApiFactoryOptions` | 可选配置 |

**ApiFactoryOptions 结构：**

```ts
interface ApiFactoryOptions {
  stringifyTargetKey?: boolean          // 是否将 target_key 转为字符串
  transformParams?: (params: any) => any // 参数转换函数
  transformBody?: (body: any) => any     // 请求体转换函数
}
```

**返回值：** API 对象

**返回的 API 对象：**

| 方法 | 说明 |
|---|---|
| `getList(params?)` | 获取列表 |
| `getOne(id)` | 获取单个 |
| `create(data)` | 创建 |
| `update(id, data)` | 更新 |
| `patch(id, data)` | 部分更新 |
| `delete(id)` | 删除 |
| `get<R>(url, params?)` | 自定义 GET |
| `post<R>(url, data?)` | 自定义 POST |
| `put<R>(url, data?)` | 自定义 PUT |
| `patchRequest<R>(url, data?)` | 自定义 PATCH |
| `deleteRequest<R>(url, data?)` | 自定义 DELETE |

**示例：**

```ts
import type { Article } from '@flecblog/core-nuxt'

const articleApi = createApi<Article>('/articles')

// 获取列表
const list = await articleApi.getList({ page: 1, page_size: 10 })

// 获取单个
const article = await articleApi.getOne(1)

// 创建
const newArticle = await articleApi.create({ title: '新文章', content: '...' })

// 更新
await articleApi.update(1, { title: '更新标题' })

// 删除
await articleApi.delete(1)
```

## apiRequest

通用请求（自动携带 token + 401 自动刷新）。

```ts
const data = await apiRequest<T>(url, options?)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `url` | `string` | 请求路径 |
| `options` | `FetchOptions` | ofetch 选项 |

**返回值：** 响应数据

**示例：**

```ts
const data = await apiRequest('/custom/endpoint', {
  method: 'POST',
  body: { key: 'value' }
})
```

**通常不需要直接使用此函数，使用 `createApi` 或 composable 函数即可。**

## 常量

### BACKEND_DATE_FORMAT

后端日期格式常量。

```ts
const BACKEND_DATE_FORMAT = 'YYYY-MM-DD HH:mm:ss'
```

**示例：**

```ts
import { BACKEND_DATE_FORMAT } from '@flecblog/core-nuxt'

console.log(BACKEND_DATE_FORMAT) // 'YYYY-MM-DD HH:mm:ss'
```
