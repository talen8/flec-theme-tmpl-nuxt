# 分类与标签

分类、标签查询相关的函数。

## useCategory

按 slug 获取分类。

```ts
const { category } = useCategory(slug)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `slug` | `MaybeRefOrGetter<string>` | 分类 slug |

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `category` | `Ref<Category \| null>` | 分类对象 |

**Category 结构：**

```ts
interface Category {
  id: number
  name: string
  slug: string
  description: string
  cover: string
  article_count: number
}
```

**示例：**

```vue
<script setup>
const route = useRoute()
const { category } = useCategory(() => route.params.slug)
</script>

<template>
  <div v-if="category">
    <h1>{{ category.name }}</h1>
    <p>{{ category.description }}</p>
  </div>
</template>
```

## useCategories

获取全部分类。

```ts
const { categories } = useCategories()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `categories` | `Ref<Category[]>` | 分类列表 |

**示例：**

```vue
<script setup>
const { categories } = useCategories()
</script>

<template>
  <div v-for="cat in categories" :key="cat.id">
    <NuxtLink :to="`/category/${cat.slug}`">
      {{ cat.name }} ({{ cat.article_count }})
    </NuxtLink>
  </div>
</template>
```

## useTag

按 slug 获取标签。

```ts
const { tag } = useTag(slug)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `slug` | `MaybeRefOrGetter<string>` | 标签 slug |

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `tag` | `Ref<Tag \| null>` | 标签对象 |

**Tag 结构：**

```ts
interface Tag {
  id: number
  name: string
  slug: string
  article_count: number
}
```

**示例：**

```vue
<script setup>
const route = useRoute()
const { tag } = useTag(() => route.params.slug)
</script>

<template>
  <div v-if="tag">
    <h1>#{{ tag.name }}</h1>
    <p>{{ tag.article_count }} 篇文章</p>
  </div>
</template>
```

## useTags

获取全部标签。

```ts
const { tags } = useTags()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `tags` | `Ref<Tag[]>` | 标签列表 |

**示例：**

```vue
<script setup>
const { tags } = useTags()
</script>

<template>
  <NuxtLink v-for="tag in tags" :key="tag.id" :to="`/tag/${tag.slug}`">
    #{{ tag.name }}
  </NuxtLink>
</template>
```

## API 函数

### getCategories

获取分类列表。

```ts
const categories = await getCategories()
// 返回: Category[]
```

### getCategoryById

按 ID 获取分类。

```ts
const category = await getCategoryById(1)
// 返回: Category
```

### getCategoryBySlug

按 slug 获取分类。

```ts
const category = await getCategoryBySlug('frontend')
// 返回: Category
```

### getTags

获取标签列表。

```ts
const tags = await getTags()
// 返回: Tag[]
```

### getTagById

按 ID 获取标签。

```ts
const tag = await getTagById(1)
// 返回: Tag
```

### getTagBySlug

按 slug 获取标签。

```ts
const tag = await getTagBySlug('vue')
// 返回: Tag
```
