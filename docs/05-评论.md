# 评论

评论列表、发表、回复相关的函数。

## useComments

评论列表管理（获取/添加/删除，全局共享状态）。

```ts
const { comments, fetchComments, addComment, removeComment, resetComments, flattenComments } = useComments()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `comments` | `Ref<Comment[]>` | 评论列表 |
| `fetchComments` | `(targetType, targetKey) => Promise<void>` | 获取评论 |
| `addComment` | `(params: CreateCommentParams) => Promise<Comment>` | 添加评论 |
| `removeComment` | `(commentId: number) => Promise<void>` | 删除评论 |
| `resetComments` | `() => void` | 重置评论 |
| `flattenComments` | `(list: Comment[], depth?: number) => FlatComment[]` | 扁平化工具 |

**Comment 结构：**

```ts
interface Comment {
  id: number
  content: string
  user?: UserInfo
  parent_id?: number
  replies?: Comment[]
  created_at: string
}
```

**CreateCommentParams 结构：**

```ts
interface CreateCommentParams {
  target_type: CommentTargetType  // 'article' | 'page'
  target_key: string | number     // 目标标识
  content: string                 // 评论内容
  parent_id?: number              // 父评论 ID（回复时）
  guest_info?: GuestInfo          // 游客信息（未登录时）
}
```

**示例：**

```vue
<script setup>
const route = useRoute()
const { data: article } = useArticle(route.params.slug)
const { comments, fetchComments, addComment } = useComments()

// 文章加载后获取评论
watch(article, (a) => {
  if (a) {
    fetchComments('article', a.id)
  }
}, { immediate: true })

// 发表评论
const handleComment = async (content) => {
  await addComment({
    target_type: 'article',
    target_key: article.value.id,
    content
  })
}

// 回复评论
const handleReply = async (parentId, content) => {
  await addComment({
    target_type: 'article',
    target_key: article.value.id,
    content,
    parent_id: parentId
  })
}
</script>
```

## fillComment

填充评论文本框并滚动聚焦（用于"引用评论"等场景）。

```ts
fillComment(content)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `content` | `string` | 要填充的评论文本 |

**示例：**

```vue
<script setup>
const handleQuote = (comment) => {
  fillComment(`> ${comment.content}\n\n`)
}
</script>

<template>
  <button @click="handleQuote(comment)">引用</button>
</template>
```

## flattenComments

将嵌套评论扁平化为带深度的列表（用于列表渲染）。

```ts
const flatList = flattenComments(commentList, depth?)
```

**参数：**

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `commentList` | `Comment[]` | - | 嵌套评论数组 |
| `depth` | `number` | `0` | 当前递归深度 |

**返回值：** `FlatComment[]` 扁平化后的评论列表

**FlatComment 结构：**

```ts
interface FlatComment {
  comment: Comment
  depth: number
}
```

**示例：**

```vue
<script setup>
const { comments } = useComments()
const flatList = computed(() => flattenComments(comments.value))
</script>

<template>
  <div v-for="item in flatList" :key="item.comment.id" :style="{ paddingLeft: item.depth * 20 + 'px' }">
    {{ item.comment.content }}
  </div>
</template>
```

## provideCommentContext

提供评论上下文（父组件调用，子组件通过 useCommentContext 注入）。

```ts
provideCommentContext(context)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `context` | `CommentContext` | 评论上下文对象 |

**CommentContext 结构：**

```ts
interface CommentContext {
  targetType: Ref<CommentTargetType>
  targetKey: Ref<string | number>
  addComment: (content: string, guestInfo?: GuestInfo) => Promise<void>
  addReply: (commentId: number, content: string, guestInfo?: GuestInfo) => Promise<void>
  deleteComment: (commentId: number) => Promise<void>
  showLogin: () => void
  replyState: {
    replyingToId: Ref<number | null>
    replyingToNickname: Ref<string>
    startReply: (commentId: number, nickname: string) => void
    cancelReply: () => void
  }
}
```

**示例：**

```vue
<!-- 父组件 -->
<script setup>
const { addComment, addReply, removeComment } = useComments()
const { open } = useLoginModal()

provideCommentContext({
  targetType: ref('article'),
  targetKey: ref(123),
  addComment: (content) => addComment({ target_type: 'article', target_key: 123, content }),
  addReply: (id, content) => addComment({ target_type: 'article', target_key: 123, content, parent_id: id }),
  deleteComment: removeComment,
  showLogin: open,
  replyState: {
    replyingToId: ref(null),
    replyingToNickname: ref(''),
    startReply: (id, name) => { /* ... */ },
    cancelReply: () => { /* ... */ }
  }
})
</script>
```

## useCommentContext

注入评论上下文（子组件调用，需在 provideCommentContext 之后）。

```ts
const context = useCommentContext()
```

**返回值：** `CommentContext` 评论上下文对象

**示例：**

```vue
<script setup>
const { addReply, replyState } = useCommentContext()

const handleReply = async (content) => {
  await addReply(replyState.replyingToId.value, content)
  replyState.cancelReply()
}
</script>
```

## API 函数

### getComments

获取评论列表。

```ts
const data = await getComments({ target_type: 'article', target_key: '123' })
// 返回: { list: Comment[], total }
```

### createComment

发表评论。

```ts
const comment = await createComment({
  target_type: 'article',
  target_key: '123',
  content: '写得很好！'
})
// 返回: Comment
```

### deleteComment

删除评论。

```ts
await deleteComment(456)
```
