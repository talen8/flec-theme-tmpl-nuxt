# 表情

表情加载、替换相关的函数。

## loadEmojiGroups

加载表情分组。

```ts
const groups = await loadEmojiGroups(url)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `url` | `string` | 表情配置文件 URL |

**返回值：** `EmojiGroup[]` 表情分组列表

**EmojiGroup 结构：**

```ts
interface EmojiGroup {
  name: string        // 分组名称
  emojis: EmojiItem[] // 表情列表
}
```

**EmojiItem 结构：**

```ts
interface EmojiItem {
  key: string    // 表情键名（如 "smile"）
  url: string    // 表情图片 URL
}
```

**示例：**

```vue
<script setup>
const emojiGroups = ref([])

onMounted(async () => {
  emojiGroups.value = await loadEmojiGroups('/emojis/config.json')
})
</script>
```

## loadEmojiMap

加载 `:key:` → URL 映射。

```ts
const map = await loadEmojiMap(url)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `url` | `string` | 表情配置文件 URL |

**返回值：** `Record<string, string>` 键名到 URL 的映射

**示例：**

```vue
<script setup>
const emojiMap = ref({})

onMounted(async () => {
  emojiMap.value = await loadEmojiMap('/emojis/config.json')
})
</script>
```

## getEmojiMapSync

同步获取已缓存的表情映射（需先调用 loadEmojiMap）。

```ts
const map = getEmojiMapSync()
```

**返回值：** `Map<string, string> | null` 表情映射或 null

**示例：**

```ts
// 先加载
await loadEmojiMap('/emojis/config.json')

// 后续同步获取
const map = getEmojiMapSync()
if (map) {
  const emoji = map.get('smile')
}
```

## clearEmojiCache

清除表情缓存。

```ts
clearEmojiCache()
```

**使用场景：** 切换表情包配置时清除缓存。

## replaceEmojisInText

替换文本中的表情占位符。

```ts
const html = replaceEmojisInText(text, emojiMap)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `text` | `string` | 包含表情占位符的文本 |
| `emojiMap` | `Map<string, string>` | 表情映射 |

**返回值：** 替换后的 HTML 字符串

**示例：**

```vue
<script setup>
const emojiMap = ref(new Map())
const content = '今天天气真好 :smile:'

const html = computed(() => replaceEmojisInText(content, emojiMap.value))
</script>

<template>
  <div v-html="html"></div>
</template>
```

**完整示例：**

```vue
<script setup>
const emojiGroups = ref([])
const emojiMap = ref(new Map())

onMounted(async () => {
  const url = '/emojis/config.json'
  emojiGroups.value = await loadEmojiGroups(url)
  emojiMap.value = await loadEmojiMap(url)
})

const content = ref(':smile: 你好 :wave:')
const html = computed(() => replaceEmojisInText(content.value, emojiMap.value))
</script>

<template>
  <div v-html="html"></div>
</template>
```
