# 统计

站点统计、归档统计相关的函数。

## useStats

获取站点统计数据。

```ts
const { siteStats, loading } = useStats()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `siteStats` | `Ref<SiteStats \| null>` | 站点统计数据 |
| `loading` | `Ref<boolean>` | 加载状态 |

**SiteStats 结构：**

```ts
interface SiteStats {
  article_count: number    // 文章总数
  category_count: number   // 分类总数
  tag_count: number        // 标签总数
  comment_count: number    // 评论总数
  view_count: number       // 总浏览量
  user_count: number       // 用户总数
  today_views: number      // 今日浏览量
  today_comments: number   // 今日评论数
}
```

**示例：**

```vue
<script setup>
const { siteStats } = useStats()
</script>

<template>
  <div v-if="siteStats" class="stats">
    <div>{{ siteStats.article_count }} 篇文章</div>
    <div>{{ siteStats.category_count }} 个分类</div>
    <div>{{ siteStats.tag_count }} 个标签</div>
    <div>{{ siteStats.comment_count }} 条评论</div>
  </div>
</template>
```

## useArchives

获取归档统计数据。

```ts
const { archives, loading } = useArchives()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `archives` | `Ref<ArchiveItem[]>` | 归档列表 |
| `loading` | `Ref<boolean>` | 加载状态 |

**ArchiveItem 结构：**

```ts
interface ArchiveItem {
  year: number        // 年份
  month: number       // 月份
  count: number       // 文章数量
  label: string       // 显示标签（如 "2025年1月"）
}
```

**示例：**

```vue
<script setup>
const { archives } = useArchives()
</script>

<template>
  <div v-for="archive in archives" :key="`${archive.year}-${archive.month}`">
    <NuxtLink :to="`/archive/${archive.year}/${archive.month}`">
      {{ archive.label }} ({{ archive.count }})
    </NuxtLink>
  </div>
</template>
```

## API 函数

### getSiteStats

获取站点统计。

```ts
const stats = await getSiteStats()
// 返回: SiteStats
```

### getArchiveStats

获取归档统计。

```ts
const archives = await getArchiveStats()
// 返回: ArchiveItem[]
```
