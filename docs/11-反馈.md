# 反馈

反馈提交相关的函数。

## useFeedback

提交反馈。

```ts
const { submit, loading } = useFeedback()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `submit` | `(data: SubmitFeedbackParams) => Promise<void>` | 提交反馈 |
| `loading` | `Ref<boolean>` | 提交中状态 |

**SubmitFeedbackParams 结构：**

```ts
interface SubmitFeedbackParams {
  reportUrl: string      // 问题页面 URL
  reportType: ReportType // 问题类型
  description: string    // 问题描述
}
```

**ReportType 类型：**

```ts
type ReportType = 'bug' | 'feature' | 'other'
```

**示例：**

```vue
<script setup>
const { submit, loading } = useFeedback()

const form = reactive({
  reportUrl: '',
  reportType: 'bug',
  description: ''
})

const handleSubmit = async () => {
  await submit(form)
}
</script>

<template>
  <form @submit.prevent="handleSubmit">
    <input v-model="form.reportUrl" placeholder="问题页面 URL" />
    <select v-model="form.reportType">
      <option value="bug">Bug</option>
      <option value="feature">功能建议</option>
      <option value="other">其他</option>
    </select>
    <textarea v-model="form.description" placeholder="问题描述" />
    <button type="submit" :disabled="loading">提交</button>
  </form>
</template>
```

## API 函数

### submitFeedback

提交反馈。

```ts
const data = await submitFeedback({
  reportUrl: 'https://example.com/page',
  reportType: 'bug',
  description: '页面显示异常'
})
// 返回: { ticket_no: string }
```

### getFeedbackByTicketNo

按工单号查询反馈状态。

```ts
const feedback = await getFeedbackByTicketNo('T20250101001')
// 返回: Feedback
```

**Feedback 结构：**

```ts
interface Feedback {
  id: number
  ticket_no: string
  report_url: string
  report_type: ReportType
  description: string
  status: FeedbackStatus
  reply?: string
  created_at: string
}

type FeedbackStatus = 'pending' | 'processing' | 'resolved' | 'closed'
```
