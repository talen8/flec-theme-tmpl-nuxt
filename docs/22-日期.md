# 日期

日期格式化相关的函数。

## formatDateTime

格式化为 `2025-10-03 13:46:59`。

```ts
const str = formatDateTime(date)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `date` | `string \| Date \| null \| undefined` | 日期 |

**返回值：** 格式化后的字符串，无效日期返回空字符串

## formatDate

const str = formatDate(date)

## formatRelativeTime

格式化为相对时间 `2小时前`。

```ts
const str = formatRelativeTime(date)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `date` | `string \| Date \| null \| undefined` | 日期 |

**返回值：** 相对时间字符串

**示例：**

```vue
<template>
  <span>{{ formatRelativeTime(article.created_at) }}</span>
  <!-- 输出: "2小时前"、"3天前"、"2025年10月3日" -->
</template>
```

## formatMomentTime

格式化动态时间 `刚刚` / `3天前` / `10月3日`。

```ts
const str = formatMomentTime(date)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `date` | `string \| Date \| null \| undefined` | 日期 |

**返回值：** 动态时间字符串

**规则：**
- 1分钟内：`刚刚`
- 1小时内：`X分钟前`
- 24小时内：`X小时前`
- 7天内：`X天前`
- 同年：`月日`（如 `10月3日`）
- 跨年：`年月日`（如 `2024年10月3日`）

**示例：**

```vue
<template>
  <span>{{ formatMomentTime(moment.created_at) }}</span>
</template>
```

## formatForBackend

转后端格式 `2025-10-03 13:46:59`。

```ts
const str = formatForBackend(date)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `date` | `Date \| null \| undefined` | 日期对象 |

**返回值：** 后端格式字符串，无效日期返回空字符串

## parseBackendDate

解析后端日期字符串。

```ts
const date = parseBackendDate('2025-10-03 13:46:59')
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `dateString` | `string \| null \| undefined` | 后端日期字符串 |

**返回值：** `Date | null` 对象，无效字符串返回 null

## isValidDate

日期是否有效。

```ts
const valid = isValidDate(date)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `date` | `string \| Date \| null \| undefined` | 待检查的值 |

**返回值：** `boolean`

**示例：**

```vue
<script setup>
const dateStr = '2025-10-03'
if (isValidDate(dateStr)) {
  console.log('有效日期')
}
</script>
```
