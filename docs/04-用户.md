# 用户

用户信息、头像相关的函数。

## useUser

获取用户信息。

```ts
const { userInfo, fetchUserInfo, updateUserInfo } = useUser()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `userInfo` | `Ref<UserInfo \| null>` | 用户信息对象 |
| `fetchUserInfo` | `() => Promise<void>` | 拉取用户信息 |
| `updateUserInfo` | `(info: UserInfo) => void` | 更新用户信息 |

**UserInfo 结构：**

```ts
interface UserInfo {
  id: number
  email: string
  nickname: string
  avatar: string
  role: string
  created_at: string
}
```

**示例：**

```vue
<script setup>
const { userInfo } = useUser()
</script>

<template>
  <div v-if="userInfo">
    <img :src="userInfo.avatar" alt="头像" />
    <span>{{ userInfo.nickname }}</span>
  </div>
</template>
```

## useAvatar

获取用户头像。

```ts
const { avatarUrl } = useAvatar()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `avatarUrl` | `ComputedRef<string>` | 头像 URL |

**示例：**

```vue
<script setup>
const { avatarUrl } = useAvatar()
</script>

<template>
  <img :src="avatarUrl" alt="头像" />
</template>
```

## API 函数

### getUserProfile

获取用户详细信息。

```ts
const profile = await getUserProfile()
// 返回: UserInfo
```

### updateUserProfile

更新用户信息。

```ts
await updateUserProfile({ nickname: '新昵称' })
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `nickname` | `string` | 昵称（可选） |
| `avatar` | `string` | 头像 URL（可选） |

### changePassword

修改密码。

```ts
await changePassword({ old_password: '旧密码', new_password: '新密码' })
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `old_password` | `string` | 旧密码 |
| `new_password` | `string` | 新密码 |

### setPassword

首次设置密码（OAuth 用户）。

```ts
await setPassword({ password: '新密码', confirm_password: '新密码' })
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `password` | `string` | 密码 |
| `confirm_password` | `string` | 确认密码 |

### deactivateAccount

注销账号。

```ts
await deactivateAccount({ password: '当前密码' })
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `password` | `string` | 当前密码（验证身份） |

### unbindOAuth

解绑 OAuth。

```ts
await unbindOAuth('github')
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `provider` | `string` | OAuth 提供商（github、google、qq 等） |
