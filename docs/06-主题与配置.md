# 主题与配置

主题配置、系统配置、暗色模式相关的函数。

## useTheme

获取当前激活主题及其菜单。

```ts
const { themeConfig, getMenus } = useTheme()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `themeConfig` | `ComputedRef<Record<string, any>>` | 主题配置对象 |
| `getMenus` | `(type: string) => ThemeMenuItem[]` | 按类型获取菜单项列表 |

**ThemeMenuItem 结构：**

```ts
interface ThemeMenuItem {
  id: number
  title: string
  url: string
  icon: string
  sort: number
  is_enabled: boolean
  children?: ThemeMenuItem[]
}
```

**示例：**

```vue
<script setup>
const { themeConfig, getMenus } = useTheme()

// 读取配置项
const accentColor = computed(() => themeConfig.value.accent_color)

// 获取菜单
const navMenus = getMenus('navigation')
const footerMenus = getMenus('footer')
</script>

<template>
  <nav>
    <NuxtLink v-for="menu in navMenus" :key="menu.id" :to="menu.url">
      {{ menu.title }}
    </NuxtLink>
  </nav>
</template>
```

## useSysConfig

获取系统配置。

```ts
const { basicConfig, uploadConfig, oauthConfig } = useSysConfig()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `basicConfig` | `ComputedRef<Record<string, string>>` | 基础配置 |
| `uploadConfig` | `ComputedRef<Record<string, string>>` | 上传配置 |
| `oauthConfig` | `ComputedRef<Record<string, string>>` | OAuth 配置 |

**basicConfig 字段：**

| 字段 | 说明 |
|---|---|
| `title` | 站点标题 |
| `subtitle` | 站点副标题 |
| `description` | 站点描述 |
| `keywords` | 关键词 |
| `author` | 作者名 |
| `author_avatar` | 作者头像 |
| `favicon` | 网站图标 |
| `blog_url` | 博客地址 |
| `admin_url` | 管理端地址 |
| `icp` | ICP 备案号 |
| `police_record` | 公安备案号 |
| `custom_head` | 自定义 head |
| `custom_body` | 自定义 body |
| `emojis` | 表情包地址 |
| `meting_api` | Meting API 地址 |

**示例：**

```vue
<script setup>
const { basicConfig } = useSysConfig()
</script>

<template>
  <head>
    <title>{{ basicConfig.title }}</title>
    <meta name="description" :content="basicConfig.description" />
    <link rel="icon" :href="basicConfig.favicon" />
  </head>
</template>
```

## useDarkMode

暗色模式控制。

```ts
const { isDark, toggleTheme, initAutoSwitch } = useDarkMode()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `isDark` | `Ref<boolean>` | 是否暗色模式 |
| `toggleTheme` | `() => void` | 切换亮/暗模式 |
| `initAutoSwitch` | `(lightTime: string, darkTime: string) => void` | 初始化自动切换 |

**示例：**

```vue
<script setup>
const { isDark, toggleTheme } = useDarkMode()
</script>

<template>
  <button @click="toggleTheme">
    {{ isDark ? '🌞 亮色' : '🌙 暗色' }}
  </button>
</template>
```

**自动切换：**

```vue
<script setup>
const { themeConfig } = useTheme()
const { initAutoSwitch } = useDarkMode()

// 根据主题配置自动切换
onMounted(() => {
  const lightTime = themeConfig.value.theme_light_start || '06:00:00'
  const darkTime = themeConfig.value.theme_dark_start || '18:00:00'
  initAutoSwitch(lightTime, darkTime)
})
</script>
```

## API 函数

### getActiveTheme

获取前台激活主题信息。

```ts
const theme = await getActiveTheme()
// 返回: { slug, name, version, config, menus, ... }
```

### getSettingGroup

获取配置组。

```ts
const basic = await getSettingGroup('basic')
// 返回: { 'basic.title': 'FlecBLOG', 'basic.description': '...', ... }
```
