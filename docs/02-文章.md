# 文章

文章列表、详情、搜索相关的函数。

## useCurrentArticle

获取当前正在浏览的文章（跨页面共享状态）。

```ts
const { currentArticle, setCurrentArticle, clearCurrentArticle } = useCurrentArticle()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `currentArticle` | `Ref<Article \| null>` | 当前文章对象 |
| `setCurrentArticle` | `(article: Article \| null) => void` | 设置当前文章 |
| `clearCurrentArticle` | `() => void` | 清除当前文章 |

**使用场景：** 在文章详情页设置当前文章，其他组件（如目录、移动端目录）可以读取。

```vue
<script setup>
const { currentArticle } = useCurrentArticle()

// 在文章详情页设置
const { data: article } = useArticle(slug)
watch(article, a => setCurrentArticle(a ?? null), { immediate: true })
</script>
```

## useArticle

按 slug 获取文章详情（支持 SSR）。

```ts
const { data: article, refresh, error } = useArticle(slug)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `slug` | `MaybeRefOrGetter<string>` | 文章 slug，支持 ref / computed / getter |

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `data` | `Ref<Article \| null>` | 文章对象 |
| `refresh` | `() => Promise<void>` | 刷新方法 |
| `error` | `Ref<Error \| null>` | 错误信息 |

**示例：**

```vue
<script setup>
const route = useRoute()
const { data: article, error } = useArticle(() => route.params.slug)
</script>
```

## useArticleList

分页获取文章列表（支持 SSR）。

```ts
const { data, page, totalPages, refresh } = useArticleList(query?)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `query` | `MaybeRefOrGetter<ArticleQuery>` | 筛选条件，可选 |

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `data` | `Ref<PaginationData<Article> \| null>` | 分页数据，包含 `list`, `total`, `page`, `page_size` |
| `page` | `Ref<number>` | 当前页码 |
| `totalPages` | `ComputedRef<number>` | 总页数 |
| `refresh` | `() => Promise<void>` | 刷新方法 |

**示例：**

```vue
<script setup>
const { data, page, totalPages } = useArticleList()
const articles = computed(() => data.value?.list || [])
</script>

<template>
  <article v-for="article in articles" :key="article.id">
    <NuxtLink :to="article.url">{{ article.title }}</NuxtLink>
  </article>
  
  <div v-if="totalPages > 1">
    <button :disabled="page <= 1" @click="page--">上一页</button>
    <span>{{ page }} / {{ totalPages }}</span>
    <button :disabled="page >= totalPages" @click="page++">下一页</button>
  </div>
</template>
```

**带筛选条件：**

```vue
<script setup>
const route = useRoute()
const categorySlug = computed(() => route.params.slug)
const { data } = useArticleList(() => ({ category: categorySlug.value }))
</script>
```

## useSearch

搜索文章（客户端交互式）。

```ts
const { results, total, loading, search, reset } = useSearch()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `results` | `Ref<Article[]>` | 搜索结果列表 |
| `total` | `Ref<number>` | 结果总数 |
| `loading` | `Ref<boolean>` | 加载状态 |
| `search` | `(keyword, page?, pageSize?) => Promise<void>` | 执行搜索 |
| `reset` | `() => void` | 重置结果 |

**示例：**

```vue
<script setup>
const { results, loading, search, reset } = useSearch()

const handleSearch = (keyword) => {
  if (keyword.trim()) {
    search(keyword, 1, 10)
  } else {
    reset()
  }
}
</script>
```

## useRandomArticle

随机跳转到一篇文章。

```ts
const { loading, go } = useRandomArticle()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `loading` | `Ref<boolean>` | 跳转中状态 |
| `go` | `() => Promise<void>` | 执行随机跳转 |

**示例：**

```vue
<template>
  <button @click="go" :disabled="loading">随机阅读</button>
</template>
```

## API 函数

以下函数可直接调用，通常在 composable 内部使用。

### getArticleList

```ts
const data = await getArticleList({ page: 1, page_size: 10 })
// 返回: { list: Article[], total, page, page_size }
```

### getArticleBySlug

```ts
const article = await getArticleBySlug('hello-world')
// 返回: Article
```

### searchArticles

```ts
const data = await searchArticles('vue', { page: 1, page_size: 5 })
// 返回: { list: Article[], total, page, page_size }
```

### getRandomArticleSlug

```ts
const slug = await getRandomArticleSlug()
// 返回: string (文章 slug)
```
