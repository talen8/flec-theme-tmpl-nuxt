# 订阅

邮箱订阅相关的函数。

## useSubscribe

邮箱订阅/退订。

```ts
const { subscribe, unsubscribe, loading } = useSubscribe()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `subscribe` | `(email: string) => Promise<void>` | 订阅 |
| `unsubscribe` | `(token: string) => Promise<void>` | 退订 |
| `loading` | `Ref<boolean>` | 操作中状态 |

**示例：**

```vue
<script setup>
const { subscribe, unsubscribe, loading } = useSubscribe()

const email = ref('')

const handleSubscribe = async () => {
  await subscribe(email.value)
}
</script>

<template>
  <div>
    <input v-model="email" type="email" placeholder="输入邮箱" />
    <button @click="handleSubscribe" :disabled="loading">订阅</button>
  </div>
</template>
```

**退订说明：** 退订需要传入订阅时收到的退订 token（通常在邮件中的退订链接里）。

## API 函数

### subscribe

订阅。

```ts
await subscribe('user@example.com')
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `email` | `string` | 邮箱地址 |

### unsubscribe

退订。

```ts
await unsubscribe(token)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `token` | `string` | 退订 token（从邮件中的退订链接获取） |
