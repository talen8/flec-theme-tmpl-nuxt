# 友链

友链列表、申请相关的函数。

## useFriends

获取友链和友链分组。

```ts
const { data, refresh, loading } = useFriends()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `data` | `Ref<FriendGroupedResponse \| null>` | 友链分组数据 |
| `refresh` | `() => Promise<void>` | 刷新方法 |
| `loading` | `Ref<boolean>` | 加载状态 |

**FriendGroupedResponse 结构：**

```ts
interface FriendGroupedResponse {
  groups: FriendGroup[]
  ungrouped: Friend[]
}
```

**FriendGroup 结构：**

```ts
interface FriendGroup {
  id: number
  name: string
  description: string
  friends: Friend[]
}
```

**Friend 结构：**

```ts
interface Friend {
  id: number
  name: string
  url: string
  description: string
  avatar: string
  is_approved: boolean
}
```

**示例：**

```vue
<script setup>
const { data } = useFriends()
</script>

<template>
  <div v-if="data">
    <div v-for="group in data.groups" :key="group.id">
      <h2>{{ group.name }}</h2>
      <div v-for="friend in group.friends" :key="friend.id">
        <a :href="friend.url" target="_blank">
          <img :src="friend.avatar" :alt="friend.name" />
          <span>{{ friend.name }}</span>
        </a>
      </div>
    </div>
  </div>
</template>
```

## useFriendApply

提交友链申请。

```ts
const { apply, loading } = useFriendApply()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `apply` | `(data: FriendApplyRequest) => Promise<void>` | 提交申请 |
| `loading` | `Ref<boolean>` | 提交中状态 |

**FriendApplyRequest 结构：**

```ts
interface FriendApplyRequest {
  name: string      // 网站名称
  url: string       // 网站地址
  description: string // 网站描述
  avatar: string    // 头像地址
}
```

**示例：**

```vue
<script setup>
const { apply, loading } = useFriendApply()

const form = reactive({
  name: '',
  url: '',
  description: '',
  avatar: ''
})

const handleSubmit = async () => {
  await apply(form)
}
</script>
```

## API 函数

### getFriends

获取友链列表。

```ts
const data = await getFriends(params?)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `params` | `FriendQueryParams` | 查询参数（可选） |

**FriendQueryParams 结构：**

```ts
interface FriendQueryParams {
  is_approved?: boolean  // 是否只获取已审核的
}
```

**返回值：** `FriendGroupedResponse`

**示例：**

```ts
// 获取所有友链
const all = await getFriends()

// 只获取已审核的
const approved = await getFriends({ is_approved: true })
```

### applyFriend

提交友链申请。

```ts
await applyFriend({
  name: '我的博客',
  url: 'https://example.com',
  description: '一个技术博客',
  avatar: 'https://example.com/avatar.png'
})
```
