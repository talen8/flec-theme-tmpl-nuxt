## 快速上手

所有函数无需 import，直接在 `.vue` / `.ts` 文件中调用：

```vue
<script setup>
// 获取文章列表
const { data } = useArticleList()
const articles = computed(() => data.value?.list || [])

// 获取主题配置
const { themeConfig, getMenus } = useTheme()
const navMenus = getMenus('navigation')

// 获取系统配置
const { basicConfig } = useSysConfig()
</script>
```
