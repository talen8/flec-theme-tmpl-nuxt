# 认证

登录、注册、OAuth 相关的函数。

## isLoggedIn

响应式登录状态，可直接在模板中使用。

```vue
<template>
  <div v-if="isLoggedIn">已登录</div>
  <div v-else>未登录</div>
</template>
```

## useAuth

获取登录状态。

```ts
const isAuth = useAuth()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `isAuth` | `ComputedRef<boolean>` | 是否已登录 |

## useAuthActions

登录、注册、找回密码等操作。

```ts
const { loginUser, registerUser, forgotPasswordUser, resetPasswordUser } = useAuthActions()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `loginUser` | `(params: LoginParams) => Promise<void>` | 登录 |
| `registerUser` | `(params: RegisterParams) => Promise<void>` | 注册 |
| `forgotPasswordUser` | `(params: ForgotPasswordParams) => Promise<void>` | 发送验证码 |
| `resetPasswordUser` | `(params: ResetPasswordParams) => Promise<void>` | 重置密码 |

**示例：**

```vue
<script setup>
const { loginUser } = useAuthActions()

const handleLogin = async () => {
  await loginUser({ email: 'user@example.com', password: '123456' })
}
</script>
```

## useLoginModal

控制登录弹窗显示/隐藏。

```ts
const { isOpen, open, close, onSuccess } = useLoginModal()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `isOpen` | `Ref<boolean>` | 弹窗是否打开 |
| `open` | `() => void` | 打开弹窗 |
| `close` | `() => void` | 关闭弹窗 |
| `onSuccess` | `(callback: () => void) => void` | 登录成功回调 |

**示例：**

```vue
<script setup>
const { open } = useLoginModal()
</script>

<template>
  <button @click="open">登录</button>
</template>
```

## useBindEmail

邮箱绑定提示。

```ts
const { triggerGlobal } = useBindEmail()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `triggerGlobal` | `() => void` | 触发全局邮箱绑定提示 |

## Token 管理

### accessToken

当前 token 的 ref。

```ts
console.log(accessToken.value) // 当前 token 或 null
```

### setAccessToken

设置 token。

```ts
setAccessToken('eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...')
```

### getAccessToken

读取 token。

```ts
const token = getAccessToken()
```

### clearAccessToken

清除 token。

```ts
clearAccessToken()
```

### logoutUser

登出（清除 token + 跳转首页）。

```ts
logoutUser()
```

## API 函数

### login

```ts
const data = await login({ email: 'user@example.com', password: '123456' })
// 返回: { access_token: string }
```

### register

```ts
const data = await register({ email: 'user@example.com', nickname: '用户', password: '123456' })
// 返回: { access_token: string }
```

### refreshToken

```ts
const data = await refreshToken()
// 返回: { access_token: string }
```

### forgotPassword

```ts
await forgotPassword({ email: 'user@example.com' })
```

### resetPassword

```ts
await resetPassword({ email: 'user@example.com', code: '123456', password: 'newpass' })
```

### logout

```ts
await logout()
```

### getOAuthUrl

获取 OAuth 登录地址。

```ts
const url = getOAuthUrl(provider, redirect)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `provider` | `string` | OAuth 提供商（github、google、qq、microsoft、oidc、wechat） |
| `redirect` | `string` | 回调地址 |

**返回值：** 跳转地址字符串

### getOAuthBindUrl

获取 OAuth 绑定地址。

```ts
const url = getOAuthBindUrl(provider, redirect, token)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `provider` | `string` | OAuth 提供商 |
| `redirect` | `string` | 回调地址 |
| `token` | `string` | 当前 access_token |

**返回值：** 跳转地址字符串

### getWechatQrcode

获取微信扫码登录二维码。

```ts
const { blob, scene } = await getWechatQrcode()
```

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `blob` | `Blob` | 二维码图片 |
| `scene` | `string` | 场景值，用于轮询 |

### getWechatScene

轮询微信扫码状态。

```ts
const data = await getWechatScene(scene)
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| `scene` | `string` | 场景值 |

**返回值：**

| 属性 | 类型 | 说明 |
|---|---|---|
| `status` | `'pending' \| 'success'` | 扫码状态 |
| `token` | `string` | 登录成功后的 token |
